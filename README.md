# Daily Security Briefing

A daily, open-source situation briefing on four areas:

| Section | Covers |
|---|---|
| **Domestic US Security** | Cyberattacks, breaches and exploited vulnerabilities hitting US organizations; CISA, FBI and DHS security actions; terrorism and espionage on US soil |
| **China / Taiwan** | PLA activity, cross-strait pressure, espionage, Indo-Pacific security |
| **Russia / Ukraine** | The war, strikes and weapons, sabotage, ceasefire talks, Russia's posture toward NATO |
| **US / Iran** | Iran's nuclear program, the IRGC and its proxies, Gulf and Strait of Hormuz security |

Each day is one file in [`briefings/`](briefings/), named by date (`YYYY-MM-DD.md`).

## How to read a section

- **BLUF** (Bottom Line Up Front) — the single most important reported development, stated first.
- **Key developments** — what happened, with the outlet that reported it.
- **Analyst comment** — judgments, kept separate from the facts, with a stated confidence (low / moderate / high).
- **Gaps / indicators** — what is still unknown and what to watch.
- **Sources** — every article used, linked to the original.

## How it is made

1. Recent items are collected from recognized news and defense-analysis outlets.
2. Ads, press releases, opinion pieces and off-topic stories are filtered out.
3. A language model running on my own hardware writes each section **from those items only**.

## Please note

- These are **machine-written summaries of public reporting**, not verified intelligence or advice. Check the linked sources before relying on anything here.
- The model can make mistakes: misattribute an event, garble a number, or miss context.
- Views here are not those of any employer, client or affiliated organization.
